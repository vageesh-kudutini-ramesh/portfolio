Who this covers

This Privacy Policy applies to the personal portfolio website of Vageesh Kudutini Ramesh (the "Site").

Information collected

If you use the contact form, the Site collects:

  • Your name
  • Your email address
  • The message you submit

Form submissions are processed through Netlify Forms (or equivalent hosting form handling) so that messages can be delivered to the site owner.

The optional "Ask AI" chatbot uses a fixed profile of public career information. On the live Netlify site, questions are sent to a Netlify Function (/.netlify/functions/chat) that calls OpenRouter to generate a reply. The OpenRouter API key stays in Netlify environment variables and is not exposed in the browser.

Chat transcripts are kept in the browser for the current session only and are not stored by this Site as a persistent message log. OpenRouter (and the underlying model provider) may process message content to generate replies according to their own policies.
